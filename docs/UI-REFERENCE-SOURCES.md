# Desktop UI reference sources

Retrieved 2026-10-18 from official Rize documentation and release announcements.
These are references for the desktop application, not its marketing website.
The source images and original application code are not bundled in this repository.

## Selected appearance

The existing dark theme is retained. The current grouped navigation comes from the
official sidebar guide; the August day-calendar image establishes the desktop frame.
Older Windows Timer and entity screenshots establish the timer and editor shapes.
Light-theme Agent, timesheet, and resourcing screenshots inform layout rather than
a new theme or new capabilities.

- Frame reference: 1280 × 720 pixels; sidebar 208 px, header 37 px, footer 54 px, summary rail 348 px.
- Font: Lato, confirmed by the public app font declarations.
- Classic dark tokens: background `#121117`, cards `#1c1b22`, fields/borders `#2b2a30`, selected controls `#3d3b46`, text `#d0d0d0`, focus `#00edff`.
- Current navigation: [Sidebar and Navigation](https://docs.rize.io/getting-started/sidebar-navigation).

## Scope boundaries

Existing commands, persistence, financial data, permissions, and provider consent are retained.
The update adds no AI scheduling, notifications, invoice email delivery, or other capabilities
that appear in official screenshots but are absent from this application. Existing Overview,
Integrations, Music, Updates, and Settings remain reachable through the workspace menu or footer.

The public Agent reference contains an orb with no standalone source image located.
Its image slot is unfilled rather than embedding a fabricated screenshot asset.
A rendered, same-state visual comparison is still required; see [design-qa.md](../design-qa.md).
